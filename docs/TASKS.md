# Задачи M0–M8: что сделано

Версия 1.5-cs2. Порядок и проверки — из `docs/TASKS.md` пакета 1.4, без Standoff 2, плюс изменения владельца 1.5 (M9). Проверки автоматизированы в `tests/`, запуск `python -m pytest`.

| Задача | Статус | Проверки (тесты) |
| --- | --- | --- |
| **M0. Каркас и конфиг** | Сделано на Python (см. `docs/ARCHITECTURE.md`). `config/skins.json`, схема по `reference/schema.sql`, `consolidated()` перенесён | Шансы кейса = сумма шансов скинов, всё 100%; `consolidated()` совпадает с `odds_lab.py` до 3 знаков на шкалах своих кейсов; каждый кейс 78–82% с гарантиями; гарантия, выводящая возврат из коридора, ловится проверкой (`test_odds.py`) |
| **M1. Ядро** | Сделано: «обещание и раскрытие», `roll()` как в `odds_lab.py`, удача, мягкие гарантии у каждого кейса свои | 1 000 000 бросков в пределах 3σ; 200 000 открытий с гарантиями совпадают с `consolidated()`; `odds_lab.roll` пересчитывает так же; гарантии на 51/60 и 281/300 |
| **M2. Каталог, цены, кейсы** | Сделано: `cs2_skins.csv`, медиана Skinport и CS2 Market, курс ЦБ, ±30% за неделю, 18 своих кейсов по правилам, лента с сервера | float в пределах min/max; скин только из своего кейса; возврат каждого кейса 78–82%; цены в копейках |
| **M3. API** | Сделано: `/v1`, страна и валюта, спин по схеме, коллекция, отмена продажи, замок, витрина, идемпотентность, лимиты | 50 параллельных запросов с одним ключом → 1 дроп; 50 спинов при балансе на 10 → 10 дропов и баланс 0; сумма `ledger` = баланс; продажа и отмена возвращают то же состояние; игрок из KZ и RU платят одинаково (`test_service.py`, `test_api.py`) |
| **M4. Мини-приложение** | Сделано: вкладки Кейсы / Апгрейды / Контракты / Инвентарь / Ещё, сетка кейсов по категориям, страница кейса с шансом каждого скина, ×1/×3/×5/×10, лента прокрутки, подтверждение без паузы, валюта страны, «Шансы», «Честная игра» с проверкой в браузере, последний дроп после обрыва | Прогон в браузере 400×860 на сервере и в превью (Playwright): кейс, контракт, апгрейд, быстрая продажа, рынок, магазин, колесо, без ошибок в консоли |

| **M6. Контракты, апгрейды, рынок, обмены** | Сделано: контракты 3–10 предметов любой редкости, апгрейды 0,8 / 80% без лимита доли ставки, рынок за монеты с вилкой и комиссией, заявки, обмены. Рынок за Stars за флагом | 10 000 контрактов: цена результата в среднем равна цели, средний множитель 0,78–0,82; 100 000 апгрейдов → 80–90%; ставка 100% баланса проходит; предмет не может быть сразу на рынке и в обмене (гонка); комиссия списывается |
| **M7. Удержание и социальное** | Сделано: колёса дня и недели, задания, розыгрыш с хешем зерна, рейтинги (по умолчанию друзья), рефералы после 10 спинов, дуэли без ставок, шеринг PNG. Кланы и хардкор — версия 1.1, не сделаны | Среднее колеса ≈ 1,08 кейса; реферал не выдаётся до 10 спинов; розыгрыш воспроизводится по зерну |

| **M8. Админка** | Сделано: вход по `ADMIN_IDS` + TOTP, `admin_audit`, экономика с алертом и «приток на активного игрока», версии конфига с проверкой и сравнением, предметы (история, заморозка), откат продажи, бан, антифрод, возвраты Stars | Конфиг с суммой не 100% не сохраняется; откат оставляет запись в журнале; журналы нельзя изменить |
