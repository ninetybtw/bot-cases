# Данные скинов CS2

Из пакета 1.4. Standoff 2 в боте не делаем, поэтому `so2_skins.csv` сюда не входит.

| Файл | Что внутри | Строк |
|---|---|---|
| `cs2_skins.csv` | Все скины CS2 на уровне рыночного лота: каждый рисунок в каждом износе, StatTrak и Souvenir, ванильные ножи | 21 407 (2 126 рисунков) |
| `cs2_other_items.csv` | Наклейки, брелоки, агенты, нашивки, граффити, кейсы и прочее. На запуске не выпадают, задел для событий и косметики | 26 936 |

Цены в CSV не заполнены: бот берёт их сам в `tools/build_catalog.py` и пишет в `data/catalog.json` в копейках игрового рубля.

Соответствие редкостей CS2: Mil-Spec → Редкий, Restricted → Эпик, Classified → Легендарный, Covert → Мифический, ★ ножи и перчатки → Секретный, Contraband → Эксклюзив. Колонка `cases` задаёт состав кейсов, `in_case_pool` — выпадает ли лот из кейсов. Фазы Doppler в CSV не различаются по названию, сборщик каталога берёт их из ByMykel/CSGO-API.
