# Кейсы CS2 — Telegram-бот и мини-приложение

Бот по ТЗ [docs/TZ.md](docs/TZ.md), только CS2 (скины Standoff 2 убраны). Открываешь настоящие кейсы CS2, выпадают скины с износом, float, узором и StatTrak™, цены берутся с рынка Skinport.

## Что работает

| Часть | Что сделано |
| --- | --- |
| Каталог | 8 кейсов (Kilowatt, Fracture, Recoil, Revolution, Clutch, Fever, Gallery, Dreams & Nightmares), 347 предметов с ножами и перчатками, цена каждого износа и StatTrak™ с рынка |
| Спин | ×1 / ×5 / ×10, результат только на сервере, шансы Valve (79,92 / 15,98 / 3,20 / 0,64 / 0,26%), цена кейса = средний дроп / 0,9 |
| Гарантии | мягкая гарантия Эпика к 60-му кейсу и Легендарного к 300-му, шанс растёт с 51-го и 281-го |
| Бесплатные спины | 3 на старте, 1 раз в 3 часа, копятся до 3, работают на самом дешёвом кейсе |
| Коллекция | 200 мест, фильтры, поиск, сортировка, карточка предмета, замок, продажа за 60%, «Продать дубли» |
| Апгрейдер | до 3 предметов + монеты, шанс = ставка ÷ цель × 0,85, запчасти 10% и +3% к следующему шансу, 10 в сутки, подтверждение с паузой для Эпика+ |
| 5 в 1 | 5 предметов одной ступени → ступень выше из тех же кейсов, Эпик+ с шансом 70%, float как в trade-up CS2 |
| Колесо и задания | колесо раз в сутки (суммы в ценах самого дешёвого кейса), 3 ежедневных задания |
| Честная игра | HMAC-SHA256(ключ сервера, «ключ игрока:nonce:шаг»), хэш ключа виден заранее, ключ раскрывается при смене пары |
| Защита | проверка подписи `initData`, лимит запросов, транзакции с проверкой версии предмета, идемпотентные спины и продажи, журнал предметов и денег |
| Бот | `/start` с кнопкой «Играть», реферальная ссылка (`ref_<id>`, 3 спина после 10 кейсов друга), `/terms`, `/paysupport` |

Пока не сделано (по ТЗ это версии 1.1 и позже): рынок между игроками, обмен, дуэли, рейтинги, кланы, хардкор, покупки за Stars, уведомления, админка.

## Запуск

```bash
python -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env        # впиши BOT_TOKEN, BOT_USERNAME, WEBAPP_URL
.venv/bin/python -m skinsbot
```

Сервер слушает `PORT` и отдаёт мини-приложение с `/`. Telegram открывает мини-приложение только по HTTPS, поэтому `WEBAPP_URL` должен вести на этот сервер через HTTPS (nginx, Caddy или туннель). Для разработки без Telegram: `DEV_MODE=1` и открыть `http://localhost:8080`.

## Каталог и цены

```bash
.venv/bin/python tools/build_catalog.py   # скачать состав кейсов и цены, пересобрать data/catalog.json
```

Запускать раз в сутки. Состав кейсов из [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API), цены из публичного API Skinport (медиана продаж). Если у лота нет цены, она считается от того же предмета в другом износе, затем медианой похожих лотов. Цена кейса меняется не больше чем на ±30% за пересборку. Список кейсов — `CASES` в `tools/build_catalog.py`, все числа игры — `skinsbot/rules.py`.

## Превью

```bash
.venv/bin/python tools/build_preview.py   # preview/dist: чат бота + мини-приложение в демо-режиме
```

Демо работает без сервера: `webapp/mock.js` повторяет серверную логику в браузере, картинки вшиты в `demo-data.js`.

## Тесты

```bash
.venv/bin/python -m pytest
```

Проверяют возврат каждого кейса (88–92%), частоты ступеней, гарантии, удачу, апгрейдер (возврат < 100%), контракты, подпись Telegram, идемпотентность, энергию, рефералов и задания.

## Устройство

```
skinsbot/rules.py     все числа из ТЗ
skinsbot/game.py      генератор и чистая логика: спин, износ, апгрейд, контракт, колесо
skinsbot/service.py   операции с базой (SQLite), каждая в одной транзакции
skinsbot/web.py       HTTP API мини-приложения
skinsbot/bot.py       Telegram-бот на aiogram
webapp/               мини-приложение (без сборки, чистый JS)
tools/                сборка каталога и превью
```
