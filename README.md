# Кейсы CS2 — Telegram-бот и мини-приложение

Бот по ТЗ 1.5 (`docs/TZ.md`), **только CS2**: скины Standoff 2 не делаем. Открываешь свои кейсы в духе кейс-сайтов — от бесплатной «Халявы» до «Мажора», выпадают скины CS2 с износом, float, узором и StatTrak™, цены с рынка в игровых рублях по курсу ЦБ, на экране — в валюте страны игрока.

## Что есть

| Часть | Что сделано |
| --- | --- |
| Каталог и цены | 18 своих кейсов в 5 категориях (популярные, оружие, по редкости, ножи и перчатки, премиум), 250 скинов из `data/skins/cs2_skins.csv`; медиана Skinport и CS2 Market, USD → рубли по курсу ЦБ; цена кейса = средний дроп с гарантиями / 0,8, не больше ±30% за неделю |
| Спин | ×1/×3/×5/×10, бесплатный кейс по таймеру, попытки за Stars, дневные лимиты, подтверждение от 3 000 ₽ или 30% баланса без паузы, переполнение на 48 часов, лента прокрутки с сервера |
| Шансы | Шанс каждого скина на странице кейса (чем дороже, тем реже), мягкие гарантии Запрещённого+ (51→60) и Засекреченного+ (281→300) у каждого кейса свои, удача ×1,5 … ×10 на скины дороже кейса с потолком возврата, точный возврат с гарантиями (`consolidated()`), честная игра «обещание и раскрытие» с проверкой в браузере |
| Инвентарь | 200 мест, быстрая продажа всего и по редкостям, режим «Выбрать» (продать, в контракт, в апгрейд), фильтры, поиск, сортировка, карточка с графиком 30 дней, продажа за 60% с отменой 10 минут, замок, витрина |
| Апгрейды и контракты | Апгрейды 0,8 с потолком 80% без лимита доли ставки, запчасти 10% и +3% к следующему шансу; контракты из 3–10 предметов любой редкости: сумма × множитель ×0,25 … ×10 (в среднем 0,8), float и StatTrak™ как в CS2 |
| Реклама | Карусель баннеров Telegram-каналов с пометкой «Реклама» и erid, клики в админке, без наград за подписку |
| Рынок | Лоты за монеты (вилка 50–150%, комиссия 10%, VIP 5%, удержание 24 ч), заявки на покупку, сделки, обмены между игроками. Рынок за Stars за флагом, выключен |
| Удержание | Колёса дня и недели, задания дня и недели, розыгрыш с опубликованным хешем зерна, рефералы с наградами за 1/5/10/25 друзей, рейтинги (по умолчанию друзья), дуэли без ставок, рамки и значки |
| Stars | Попытки, удача, VIP, места, набор «Старт»; месячный потолок 500 ⭐, `pre_checkout_query`, выдача по `successful_payment` один раз, возвраты. Магазин выключен флагом до юридической проверки |
| Сервис | Уведомления (2 в сутки, тишина 21–08), налог на копилку, антифрод, админка (`/admin`) с TOTP: экономика, версии конфига, предметы, откаты, баны, возвраты |

Не сделано (ТЗ относит к версии 1.1): кланы, хардкор, сезоны с медалями, пропуск сезона, батл кейсов. Подробно — `docs/TASKS.md`, спорные места пакета и принятые решения — `docs/ARCHITECTURE.md`.

## Запуск

```bash
python -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env        # BOT_TOKEN, WEBAPP_URL, ADMIN_IDS, ADMIN_TOTP_SECRET
.venv/bin/python -m skinsbot
```

Один процесс: API и мини-приложение на `PORT`, бот (long polling) и фоновые задачи раз в минуту. Telegram открывает мини-приложение только по HTTPS, поэтому `WEBAPP_URL` должен вести на этот сервер через HTTPS (nginx, Caddy или туннель). Без Telegram: `DEV_MODE=1` и `http://localhost:8080`, админка — `http://localhost:8080/admin`.

Магазин Stars включается в `config/skins.json` → `stars.shop_enabled` после проверки юристом.

## Цены

```bash
.venv/bin/python tools/build_catalog.py               # цены и курс ЦБ, пересборка data/catalog.json
.venv/bin/python tools/build_catalog.py --lisskins    # плюс Lis-Skins (выгрузка больше 1 ГБ)
.venv/bin/python tools/build_catalog.py --buff buff.csv
```

С `PRICE_UPDATE=1` сервер делает это сам каждый день в 04:00 МСК. Кейсы и их правила (оружие, редкость, вилка цен, сколько скинов) — `cases` в `config/skins.json`, там же все числа игры. `--offline` пересобирает каталог из скачанных цен без сети.

## Превью

```bash
.venv/bin/python tools/build_preview.py   # preview/dist: чат бота + мини-приложение в демо-режиме
```

Демо работает без сервера: `webapp/mock.js` повторяет API в браузере (броски настоящие, HMAC-SHA256), картинки вшиты в `demo-data.js`, остальные игроки вымышленные.

## Тесты

```bash
.venv/bin/python -m pytest
```

104 теста по проверкам `docs/TASKS.md`: возврат каждого кейса 78–82% с гарантиями, совпадение с `reference/odds_lab.py`, 1 000 000 бросков в пределах 3σ, 200 000 открытий против `consolidated()`, удача не ниже базы и не выше потолка, контракты 0,8, апгрейдер 80–90%, быстрая продажа, 50 параллельных запросов с одним ключом, гонка рынка и обмена, сумма журнала равна балансу, повторный платёж, лимит 500 ⭐, неизменяемые журналы, откат без потери истории.
